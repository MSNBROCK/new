# Northstar Banking Management System

**College Project – Online Banking Simulator**

## Features

* 14 sample client accounts
* Individual customer login
* Customer dashboard
* Sample account balances
* JIO IPO section
* Withdrawal simulator
* Terms and Conditions
* Agree / Disagree buttons
* KYC demonstration checklist
* Submission confirmation
* 30-day blue-dot tracking
* Withdrawal history

## Technologies

* HTML5
* CSS3
* JavaScript

## Installation

1. Download all project files.
2. Keep all four files in one folder.
3. Open index.html in your browser.

## GitHub Deployment

1. Create a GitHub repository.
2. Upload all four files.
3. Open Settings.
4. Select Pages.
5. Select Deploy from a branch.
6. Choose main and root.
7. Save.

## Disclaimer

This is an educational simulator. It does not process real money or perform actual banking or KYC verification.
